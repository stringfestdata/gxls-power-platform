# Pre-Class Setup Checklist

## Becoming a Citizen Developer with Power Platform

Please complete these steps **before** the session so we can jump straight into building.

---

## 1. Microsoft 365 Access

- [ ] Confirm you can sign in at [office.com](https://office.com) with a work or school account
- [ ] Verify you have access to Excel, Outlook, and Teams online
- [ ] Make sure you have a OneDrive or SharePoint location where you can store workbooks (we'll be connecting flows and apps to files stored here)

## 2. Power Automate

- [ ] Go to [make.powerautomate.com](https://make.powerautomate.com) and sign in
- [ ] If prompted, start a free trial — a trial license is fine for this class
- [ ] Confirm you can see the Power Automate home screen with "Create" in the left sidebar

## 3. Power BI Desktop

- [ ] Download and install Power BI Desktop from the [Microsoft Store](https://aka.ms/pbidesktopstore) (Windows only)
- [ ] If you're on Mac, you can follow along using the [Power BI web service](https://app.powerbi.com) — some features will differ but the core concepts apply
- [ ] Open Power BI Desktop at least once to complete initial setup

## 4. Power Apps

- [ ] Go to [make.powerapps.com](https://make.powerapps.com) and sign in
- [ ] If prompted, start a free trial
- [ ] Confirm you can see the Power Apps home screen

## 5. Copilot Studio

- [ ] Go to [copilotstudio.microsoft.com](https://copilotstudio.microsoft.com) and sign in
- [ ] If prompted, start a free trial
- [ ] Confirm you can see the Copilot Studio home screen

## 6. Download Course Files

- [ ] Download the course materials ZIP from:
  **https://github.com/stringfestdata/gxls-power-platform/archive/refs/heads/main.zip**
- [ ] Unzip the folder and upload it to your OneDrive or SharePoint
- [ ] The folder contains subfolders for each section: `1-power-automate`, `2-power-bi`, `3-power-apps`, `4-copilot-studio`

## Troubleshooting

**"I can't access Power Automate / Power Apps / Copilot Studio"**
Your organization may have Power Platform disabled. Contact your IT admin and ask them to enable Power Platform trials, or use a personal Microsoft 365 developer account: [developer.microsoft.com/microsoft-365/dev-program](https://developer.microsoft.com/en-us/microsoft-365/dev-program)

**"I don't have a work or school account"**
Power Platform requires a work/school Microsoft 365 account (not a personal @outlook.com account). The free M365 Developer Program link above will give you one.

**"Power BI Desktop won't install"**
You may need admin rights on your machine. Try the Microsoft Store version first. If that doesn't work, ask IT to install it, or plan to follow along using the Power BI web service instead.
